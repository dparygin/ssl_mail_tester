# Проверка SSL-сертификатов через PowerShell

Универсальный скрипт для получения и диагностики SSL-сертификатов удаленных серверов с использованием встроенных классов `.NET`. Поддерживает как неявное шифрование (HTTPS, SMTPS, LDAPS), так и явное (STARTTLS для SMTP). Сам скрипт доступен в файле Code.

## Особенности

* Работает без установки сторонних утилит (например, OpenSSL).
* Поддерживает явное шифрование (STARTTLS) для проверки почтовых серверов на портах 25 и 587.
* Принудительно использует современные протоколы безопасности (TLS 1.2 и TLS 1.3).
* Содержит защиту от зависаний за счет настраиваемого таймаута на сетевое подключение и потоки чтения/записи.
* Игнорирует ошибки доверия, позволяя просматривать просроченные, самоподписанные сертификаты и разорванные цепочки.
* Выводит точные причины сбоев при неудачном подключении (например, отказ в соединении, ошибки DNS или сбои SSL-рукопожатия).

## Параметры скрипта

Скрипт принимает следующие аргументы командной строки:

* **`-Server`** *(Обязательный)*: FQDN или IP-адрес целевого сервера.
* **`-Port`** *(Необязательный)*: Порт для подключения (по умолчанию `443`).
* **`-TimeoutSeconds`** *(Необязательный)*: Время ожидания в секундах (по умолчанию `5`).
* **`-StartTls`** *(Необязательный)*: Режим явного шифрования. Допустимые значения: `None` (по умолчанию) или `SMTP`.

## Примеры использования

Проверка веб-сервера по умолчанию (порт 443):

```powershell
.\Get-SSLCert.ps1 -Server "google.com"

```

Проверка почтового сервера с неявным SSL (порт 465) и увеличенным таймаутом:

```powershell
.\Get-SSLCert.ps1 -Server "mail.example.com" -Port 465 -TimeoutSeconds 10

```

Проверка почтового сервера с явным шифрованием STARTTLS (порт 587):

```powershell
.\Get-SSLCert.ps1 -Server "mail.example.com" -Port 587 -StartTls SMTP

```

Запуск скрипта из стандартной командной строки (cmd.exe):

```cmd
powershell.exe -ExecutionPolicy Bypass -File ".\Get-SSLCert.ps1" -Server "mail.example.com" -Port 465

```

## Возвращаемые данные

При успешном выполнении скрипт выводит в консоль следующие атрибуты сертификата:

* **Subject:** Кому выдан (доменное имя сервера).
* **Issuer:** Кем выдан (удостоверяющий центр).
* **NotBefore:** Дата и время начала действия.
* **NotAfter:** Дата и время окончания действия.
* **Thumbprint:** Уникальный отпечаток сертификата (хэш).
